# Mapa de viaje: Ruta a Stevens Pass

Guía de llegada para el Work & Travel en Stevens Pass (invierno 2026/27): del aeropuerto de SeaTac a Leavenworth, con horarios del shuttle, cómo pagar el transporte, qué llevar a mano y los lugares que se necesitan, cada uno con un botón que lo abre en Google Maps.

Es una página estática de un solo archivo (`index.html`), sin dependencias ni build. Sólo carga las tipografías de Google Fonts.

## Ver la página

Abrí `index.html` en el navegador, o activá GitHub Pages en *Settings → Pages → Deploy from a branch → `main` / root*.

## Datos a verificar antes de viajar

Los horarios del shuttle, las tarifas y los horarios del bus 22 pueden cambiar. La lista "Para confirmar" al final de la página reúne lo que no se pudo verificar.
